# 🎤 PresentIQ AI

### Practice Smarter. Present Better.

PresentIQ AI is an AI-powered presentation practice platform designed to help students improve their public speaking and presentation skills.

It provides an interactive environment where users can practise presentations and receive AI-generated feedback to become more confident speakers.

## ✨ Features

- User Registration and Login
- Personal Dashboard
- Presentation Practice
- AI-powered Presentation Feedback
- Presentation Recording
- Practice Results
- User-friendly Interface

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS
- **Backend:** Python, Flask
- **Database:** MySQL
- **AI Integration:** Google Gemini API
- **Tools:** VS Code, XAMPP

## ⚙️ Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/gnandhana-alt/PresentIQ-AI.git
```

**2. Open the project folder**

**3. Install the required packages**

```bash
pip install -r requirements.txt
```

**4. Configure the MySQL database**

Import `database.sql` into MySQL and configure your database credentials.

**5. Configure environment variables**

Create a `.env` file containing your Gemini API key and database credentials. Never share this file publicly.

**6. Run the application**

```bash
python app.py
```

**7. Open the local URL**

Open the URL displayed in your terminal in your browser.
